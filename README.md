# Читальня

Читалка книг внутри Obsidian. Книга открывается касанием по файлу в хранилище, а место, где ты остановился, хранится в обычной заметке — карточке книги — и вместе с ней доезжает до других устройств. Рядом с книгой пишется скелет-конспект: заметка с заголовком на каждую главу.

Этап «Читальня» экосистемы ArsMemoria. Книги добавляются формой «Добавить книгу», данные правятся в «Данных книги». Дашборд библиотеки, журнал чтения, выделения и сноски со ссылкой на место в книге — следующими версиями.

## Что умеет

- **Форматы:** EPUB, FB2, FB2 в zip (`.fbz` открывается касанием, `.fb2.zip` — через меню файла → «Открыть в Читальне»), MOBI, AZW3 и CBZ. PDF показывает встроенный просмотрщик Obsidian.
- **Без сети.** Всё нужное внутри плагина.
- **Листание** свайпом, тапом по левому или правому краю страницы, стрелками и пробелом на клавиатуре. Тап в середине прячет панели — остаётся только текст.
- **Разворот:** на широком экране, например iPad горизонтально, две страницы рядом. На iPad вертикально и на iPhone — одна.
- **Оглавление**, процент прочитанного, сколько минут осталось до конца главы, ползунок по всей книге.
- **Вид:** темы «Авто», светлая, сепия, ночная; шрифт книги, с засечками или без; размер, интерлиньяж, поля, выравнивание по ширине, переносы; страницы или прокрутка. Настройки вида свои у каждого устройства.

## Добавить книгу

Кнопка **Добавить книгу** на левой панели (или команда с тем же именем) открывает форму:

1. **Выбрать файл книги** — из «Файлов» на iPad и iPhone. Поля заполняются из файла: название, автор, год, издательство, ISBN, язык, аннотация, обложка.
2. Поправь, что нужно. Несколько авторов — через запятую. **Полка:** «Не начал», «Читаю» или «Дочитал». **Коллекции** выбираются кнопками, новая добавляется полем под ними; одна книга может быть в нескольких.
3. **Обложка…** — другая картинка вместо обложки из файла.
4. **Добавить.** Книга ложится в `06 Other/Books`, обложка в `06 Other/Archive/Files`, карточка в `03 Resources/Литература/Книги`. Все трое называются одинаково: «Автор — Название». В уведомлении — ссылка **Открыть**.

Если такая книга уже есть (тот же файл), форма скажет об этом и предложит её открыть. Если в «Книгах» уже лежит заметка «Автор — Название», она и становится карточкой; если есть только похожие, Читальня спросит, какая из них про эту книгу. Свойства, которые ты в форме не трогал, в такой заметке остаются как были, её текст тоже.

Файл, попавший в хранилище мимо кнопки (скачал прямо в папку, открыл из «Файлов»), при первом открытии показывает ту же форму — книга уже открыта за ней. Закрыл форму — книга читается без карточки, место не запоминается; форма вернётся при следующем открытии и есть в меню книги ⋮ → **Данные книги**. Если карточка этой книги тем временем приехала с другого устройства, форма закроется сама.

## Данные книги

Та же форма для правки: в меню книги ⋮ → **Данные книги**, кнопкой с карандашом в шапке карточки или командой. Рядом в шапке карточки — кнопка **Читать** (очки): открывает книгу.

Поменял название или автора — переименовывается всё сразу: файл книги, обложка, карточка и конспект, под новое «Автор — Название». Ссылки между ними Читальня переписывает сама, поэтому карточка не теряется и вторая не появляется. Ссылки на них из твоих других заметок обновляет Obsidian — как велит его настройка **Файлы и ссылки → Автоматически обновлять внутренние ссылки**; если она выключена, Obsidian спросит. Если у другой книги уже есть такое имя, новая получит «Автор — Название 2».

## Карточка книги

Карточка — обычная заметка, всё в ней читается и без плагина:

```yaml
Название: Мастер и Маргарита
Автор:
  - Михаил Булгаков
Переводчик:                 # если есть в файле
Год: 1967
Издательство: АСТ
ISBN: "9785170906227"
Язык: ru
Коллекции:
  - Русская классика
Статус: читаю               # не начал · читаю · дочитал
Прогресс: 52                # сколько прочитано, по самому дальнему месту
Глава: Глава 7              # где остановился
Начал: 2026-11-06
Закончил:                   # ставится сам, когда дочитал до конца
Обложка: "[[Михаил Булгаков — Мастер и Маргарита (обложка).jpg]]"
Файл: "[[Михаил Булгаков — Мастер и Маргарита.epub]]"
Формат: epub
Отпечаток: 5e1c0d…          # отпечаток файла, как в KOReader
Место: epubcfi(/6/14!/4/2/1:0)
Конспект: "[[Михаил Булгаков — Мастер и Маргарита (конспект)]]"
```

В тексте карточки сверху обложка, под ней аннотация (выноска «Аннотация»), ниже — что напишешь сам. Пустые свойства не пишутся.

- Открыл книгу из «Не начал» — она сама переходит в «Читаю» и получает дату «Начал». Дочитал до конца — «Дочитал» и дата «Закончил».
- Место записывается при закрытии книги, когда приложение уходит в фон, и раз в полминуты, а не на каждой странице.
- Если книгу переименовать или перенести руками, карточка найдётся по ссылке в «Файл» или по отпечатку файла.
- Обложка сжимается до 800 точек по длинной стороне (JPEG), чтобы синхронизация её не замечала.
- **Карточки из 0.1 и 0.2** с английскими свойствами (`title`, `status`, `furthest`…) Читальня переводит на русские сама, через 20 секунд после запуска Obsidian; конспекты получают «Книга» вместо `book`. Полки «хочу прочитать» больше нет: такие книги становятся «не начал». Старая карточка без обложки берёт её из книги, когда книгу откроешь. Карточки из 0.1, лежавшие рядом с файлом книги, переезжают в «Книги».

## Скелет-конспект

Кнопка **Конспект** в шапке книги создаёт заметку `03 Resources/Литература/Конспекты/Автор — Название (конспект)`: заголовок `##` на каждую главу верхнего уровня, под ним твой вложенный список. Тезисы — жирные пункты первого уровня. Карточка ссылается на конспект (свойство «Конспект»), конспект на карточку («Книга»).

- **В правой панели.** Конспект открывается в правой панели Obsidian — той же, где обратные ссылки и граф, — и пишется прямо в ней. Книга остаётся на месте, поэтому переключение мгновенное. Открыть: кнопка **Конспект** или свайп влево по шапке или по нижней строке книги (свайп по самой странице листает). Закрыть: свайп вправо по панели или касание книги. На iPad панель закрепляется булавкой внизу панели — книга и конспект видны рядом.
- **Книга ведёт.** Конспект сам встаёт на главу, которую ты читаешь: сразу, если панель на экране, или как только ты её откроешь. Пока ты печатаешь в конспекте, он не дёргается.
- **«+»** — мысль в конец ветки текущей главы, не выходя из книги. Каждая строка — отдельный пункт.
- **«Скелет главы →».** Перелистнул в следующую главу, а у прошлой скелета нет — внизу на несколько секунд появится кнопка. Она ставит пустой пункт под прошлой главой.
- **Оглавление** показывает, какие главы пройдены (✓) и у каких есть скелет. Ничего не нужно отмечать вручную: «пройдена» Читальня понимает по «Прогрессу», «скелет есть» — по тексту под заголовком.
- Заголовки можно править: глава найдёт свой заголовок, пока его начало совпадает с названием главы.

### Панель над клавиатурой

В конспекте на iPad и iPhone вместо панели Obsidian появляется своя:

| Кнопка | Что делает |
| --- | --- |
| ← → | уровень пункта выше или ниже; пункт идёт вместе с вложенными |
| ↑ ↓ | пункт вверх или вниз среди соседей, тоже с вложенными |
| свернуть | свернуть или развернуть ветку |
| новый пункт | пункт того же уровня после всей ветки |
| B | тезис: жирный и обратно |
| клавиатура | спрятать клавиатуру |

Те же действия есть командами («Конспект: уровень выше» и т. д.) — на них можно повесить сочетания клавиш. После каждого действия отступы выравниваются под настройку хранилища («Отступ табуляцией»), нумерованные списки пересчитываются. На iPhone глубокие уровни показываются с меньшим отступом.

## Настройки

- **Вид книги** — свой у каждого устройства.
- **Папка карточек** — `03 Resources/Литература/Книги`.
- **Папка конспектов** — `03 Resources/Литература/Конспекты`.
- **Папка книг** — `06 Other/Books`. Книга, открытая из другой папки, переезжает сюда, когда сохраняешь её данные.
- **Папка обложек** — `06 Other/Archive/Files`.
- **Где открывать конспект** — в правой панели или рядом с книгой (отдельная панель на широком экране, вкладка на узком; назад к книге — кнопка **Книга** в конспекте).

## Безопасность

В книге может оказаться JavaScript, а показывается она в том же окне, что и хранилище. Поэтому каждая страница книги перед показом проходит очистку: скрипты, обработчики событий, ссылки `javascript:`, встроенные фреймы и объекты удаляются, а странице ставится политика безопасности (CSP), которая запрещает скрипты и любые запросы за пределы книги. Стили книги встраиваются прямо в страницу: Obsidian 1.15 не пускает стили файлами. Внешние ссылки открываются в браузере, только если это `http`, `https` или `mailto`. Обложка и данные для формы берутся только из самого файла: адресов из интернета, которые назовёт книга, Читальня не открывает.

## Установка

1. Поставь BRAT из каталога плагинов Obsidian.
2. BRAT → **Add Beta plugin** → `agniglobal2021-cmd/ars-reader` → **Add Plugin**.
3. Включи «Читальня» в **Сторонние плагины**.

## Внешний вид

Облик задают CSS-переменные в `styles.css`, их можно переопределить сниппетом или темой, не трогая код:

| Переменная | Что задаёт |
| --- | --- |
| `--ars-reader-light-bg`, `-fg`, `-link` | цвета светлой темы (так же `sepia` и `night`) |
| `--ars-reader-font-serif`, `--ars-reader-font-sans` | шрифты «с засечками» и «без засечек» |
| `--ars-reader-ui-font`, `--ars-reader-status-size` | шрифт и размер строки состояния |
| `--ars-reader-touch` | высота строк оглавления для пальца |
| `--ars-reader-accent` | цвет ползунка |

## Разработка

```sh
npm install
npm test               # отпечаток, метаданные, свойства и их перевод, карточки, имена файлов, конспект, панель
npm run test:browser   # книги в Chromium на размерах iPad и iPhone, данные и обложки из файлов, скриншоты в test/out (нужен Playwright)
npm run build          # main.js
```

Релиз выпускается кнопкой: **Actions** → **Выпустить релиз** → **Run workflow**. Перед новым релизом подними версию в `manifest.json`, `package.json` и `versions.json` и допиши раздел в `CHANGELOG.md`.
