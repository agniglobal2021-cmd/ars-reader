# Читальня

Читалка книг внутри Obsidian. Книга открывается касанием по файлу в хранилище, а место, где ты остановился, хранится в обычной заметке — карточке книги — и вместе с ней доезжает до других устройств. Рядом с книгой пишется скелет-конспект: заметка с заголовком на каждую главу.

Этап «Читальня» экосистемы ArsMemoria. Выделения, сноски со ссылкой на место в книге и дашборд библиотеки — следующими версиями.

## Что умеет

- **Форматы:** EPUB, FB2, FB2 в zip (`.fbz` открывается касанием, `.fb2.zip` — через меню файла → «Открыть в Читальне»), MOBI, AZW3 и CBZ. PDF показывает встроенный просмотрщик Obsidian.
- **Без сети.** Всё нужное внутри плагина.
- **Листание** свайпом, тапом по левому или правому краю страницы, стрелками и пробелом на клавиатуре. Тап в середине прячет панели — остаётся только текст.
- **Разворот:** на широком экране, например iPad горизонтально, две страницы рядом. На iPad вертикально и на iPhone — одна.
- **Оглавление**, процент прочитанного, сколько минут осталось до конца главы, ползунок по всей книге.
- **Вид:** темы «Авто», светлая, сепия, ночная; шрифт книги, с засечками или без; размер, интерлиньяж, поля, выравнивание по ширине, переносы; страницы или прокрутка. Настройки вида свои у каждого устройства.

## Карточка книги

Карточка — обычная заметка в `03 Resources/Литература/Книги` с именем «Автор — Название». При первом открытии книги Читальня:

1. ищет там заметку с таким именем — и если она есть, привязывает книгу к ней (так заметка «хочу прочитать», заведённая до файла, становится карточкой);
2. если есть только похожие заметки, спрашивает, какая из них про эту книгу, или предлагает создать новую;
3. иначе создаёт карточку — по шаблону, если он задан.

Шаблон — путь в настройках или шаблон папки из Templater. Поля шаблона остаются как есть: Читальня заполняет пустые и пишет свои. Карточки из версии 0.1, лежавшие рядом с файлом книги, сами переезжают в «Книги».

Всё, что Читальня знает о книге, лежит в свойствах и читается без плагина:

```yaml
title: Мастер и Маргарита
author:
  - Михаил Булгаков
publisher: …
issued: "1967"
language: ru
ISBN: "9785170906227"
file: "[[Мастер и Маргарита.epub]]"
format: epub
fingerprint: 5e1c0d…        # отпечаток файла, как в KOReader
status: читаю               # хочу прочитать · читаю · дочитал
progress: 37                # где ты сейчас, процент
furthest: 52                # дальше всего, докуда дочитал
chapter: Глава 7
location: epubcfi(/6/14!/4/2/1:0)
outline: "[[Михаил Булгаков — Мастер и Маргарита (конспект)]]"
started: 2026-11-06
finished:                   # ставится сам, когда дочитал до конца
```

Названия библиографических полей — как в CSL-JSON, чтобы список литературы выгружался куда угодно. Если книгу переименовать или перенести, карточка найдётся по ссылке в `file` или по отпечатку файла. Место записывается при закрытии книги, когда приложение уходит в фон, и раз в полминуты, а не на каждой странице.

## Скелет-конспект

Кнопка **Конспект** в шапке книги создаёт заметку `03 Resources/Литература/Конспекты/Автор — Название (конспект)`: заголовок `##` на каждую главу верхнего уровня, под ним твой вложенный список. Тезисы — жирные пункты первого уровня. Карточка ссылается на конспект (`outline`), конспект на карточку (`book`).

- **Книга ведёт.** На iPad горизонтально конспект открывается рядом с книгой и сам встаёт на главу, которую ты читаешь. Пока ты печатаешь в конспекте, он не дёргается. На iPhone и на iPad вертикально — переключение кнопками: **Конспект** в книге, **Книга** в конспекте.
- **«+»** — мысль в конец ветки текущей главы, не выходя из книги. Каждая строка — отдельный пункт.
- **«Скелет главы →».** Перелистнул в следующую главу, а у прошлой скелета нет — внизу на несколько секунд появится кнопка. Она ставит пустой пункт под прошлой главой.
- **Оглавление** показывает, какие главы пройдены (✓) и у каких есть скелет. Ничего не нужно отмечать вручную: «пройдена» Читальня понимает по `furthest`, «скелет есть» — по тексту под заголовком.
- Заголовки можно править: глава найдёт свой заголовок, пока его начало совпадает с названием главы.

### Панель над клавиатурой

В конспекте на iPad и iPhone вместо панели Obsidian появляется своя:

| Кнопка | Что делает |
| --- | --- |
| ← → | уровень пункта выше или ниже; пункт идёт вместе с вложенными |
| ↑ ↓ | пункт вверх или вниз среди соседей, тоже с вложенными |
| свернуть | свернуть или развернуть ветку |
| новый пункт | пункт того же уровня после всей ветки |
| B | тезис: жирный и обратно |
| клавиатура | спрятать клавиатуру |

Те же действия есть командами («Конспект: уровень выше» и т. д.) — на них можно повесить сочетания клавиш. После каждого действия отступы выравниваются под настройку хранилища («Отступ табуляцией»), нумерованные списки пересчитываются. На iPhone глубокие уровни показываются с меньшим отступом.

## Настройки

- **Вид книги** — свой у каждого устройства.
- **Папка карточек** — `03 Resources/Литература/Книги`.
- **Папка конспектов** — `03 Resources/Литература/Конспекты`.
- **Шаблон карточки** — путь к шаблону. Пусто — шаблон папки из Templater, если он задан, иначе простая карточка.

## Безопасность

В книге может оказаться JavaScript, а показывается она в том же окне, что и хранилище. Поэтому каждая страница книги перед показом проходит очистку: скрипты, обработчики событий, ссылки `javascript:`, встроенные фреймы и объекты удаляются, а странице ставится политика безопасности (CSP), которая запрещает скрипты и любые запросы за пределы книги. Стили книги встраиваются прямо в страницу: Obsidian 1.15 не пускает стили файлами. Внешние ссылки открываются в браузере, только если это `http`, `https` или `mailto`.

## Установка

1. Поставь BRAT из каталога плагинов Obsidian.
2. BRAT → **Add Beta plugin** → `agniglobal2021-cmd/ars-reader` → **Add Plugin**.
3. Включи «Читальня» в **Сторонние плагины**.

## Внешний вид

Облик задают CSS-переменные в `styles.css`, их можно переопределить сниппетом или темой, не трогая код:

| Переменная | Что задаёт |
| --- | --- |
| `--ars-reader-light-bg`, `-fg`, `-link` | цвета светлой темы (так же `sepia` и `night`) |
| `--ars-reader-font-serif`, `--ars-reader-font-sans` | шрифты «с засечками» и «без засечек» |
| `--ars-reader-ui-font`, `--ars-reader-status-size` | шрифт и размер строки состояния |
| `--ars-reader-touch` | высота строк оглавления для пальца |
| `--ars-reader-accent` | цвет ползунка |

## Разработка

```sh
npm install
npm test               # отпечаток, метаданные, карточки, конспект, панель
npm run test:browser   # книги в Chromium на размерах iPad и iPhone, скриншоты в test/out (нужен Playwright)
npm run build          # main.js
```

Релиз выпускается кнопкой: **Actions** → **Выпустить релиз** → **Run workflow**. Перед новым релизом подними версию в `manifest.json`, `package.json` и `versions.json` и допиши раздел в `CHANGELOG.md`.
